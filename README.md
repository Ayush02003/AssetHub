# AssetHub

AssetHub is a full-stack asset management system designed to manage company assets efficiently. It supports role-based access, asset allocation, tracking, and notifications to streamline internal asset operations.

## Features
- Role-based access (Admin, HR, IT, Employee)
- Asset creation and management
- Asset allocation and tracking
- Maintenance and issue reporting
- Notification system for asset updates
- Dashboard with key asset metrics

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: JWT

## User Roles
- Admin: Manages users and overall system
- HR: Manages asset types and allocations
- IT: Handles maintenance and technical issues
- Employee: Requests and views assigned assets

## Setup
1. Clone the repository  
2. Install dependencies  
3. Configure environment variables  
4. Run frontend and backend servers
